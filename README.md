## ✨ About The Project

**Bánh Bao Day** is a whimsical, open-source tribute to Vietnam's fluffiest street food: the **Bánh Bao**. 

Inspired by the iconic, slightly static-filled loudspeaker recordings heard on every street corner in Vietnam, this project aims to bring the warmth, softness, and joy of a steamed bun to the web.

Whether you're a traveler missing the streets of Saigon or just someone who loves cute things, welcome home. 🇻🇳✨

## 🎨 Features

- **So Soft, So Cute**: A design system built on warm creams, pastel pinks, and the roundest `Fredoka` font we could find.
- **Interactive Joy**: Press the `Yummy!` button. Trust us. 🎊
- **The Anthem**: Auto-playing YouTube short of the Bánh Bao remix to set the mood.
- **Loudspeaker Lore**: A dedicated section to the unsung hero of street marketing—the grey horn loudspeaker.

## 🛠️ Tech Stack

Built with love and modern web tech:

## 🚀 Getting Started

Want to run your own Bánh Bao stand locally?

1. **Clone the repo**
   ```bash
   git clone https://github.com/yourusername/banhbao.day.git
   cd banhbao.day
   ```

2. **Install dependencies**
   ```bash
   yarn install
   # or npm install
   ```

3. **Steam the buns (Start the server)**
   ```bash
   yarn dev
   ```

4. **Eat!**
   Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
